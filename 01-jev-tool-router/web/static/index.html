Jev as a tool router for MCP agents

Instead of loading every MCP tool into the agent's context, Jev (TypeSafe's RLCD decision model, via the Decisions API on Vercel AI Gateway) hands the agent only the 5 or 10 tools it needs next. Each run compares Jev with OpenAI's decision model (gpt-6-luna, same Decisions API) on three public MCP benchmarks.
